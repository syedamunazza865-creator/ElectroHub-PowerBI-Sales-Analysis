# ElectroHub-PowerBI-Sales-Analysis
Interactive Power BI dashboard analyzing ElectroHub retail sales, profit, discounts, product performance, order trends, and city-wise sales using DAX and Power Query.


## Project Overview
ElectroHub is an interactive Power BI sales analysis project designed to analyze retail sales performance across different product categories, cities, customers, and time periods.

The dashboard provides insights into sales, profit, quantity sold, discounts, and order-level performance to support data-driven business decisions.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Key Business Requirements
1. Identify the top and bottom five products by sales, profit, and quantity sold.
2. Analyze sales trends across daily, monthly, quarterly, and annual periods.
3. Examine the relationship between sales and profit.
4. Compare sales, profit, and quantity sold between two selected periods.
5. Calculate average discounts by discount category.
6. Track the total number of orders.
7. Analyze order-level sales, profit, discounts, and net sales with interactive filters.
8. Compare sales performance across cities.

## Product Categories
Electronics, Footwear, Clothing, Home Appliances, Accessories, Kitchenware, Bags, and Personal Care.

## Project Deliverables
- Interactive Power BI dashboard
- Sales performance analysis
- Product and category analysis
- Time-based sales trends
- City-wise sales analysis
